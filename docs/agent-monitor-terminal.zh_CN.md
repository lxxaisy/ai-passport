# Agent Monitor 随身终端

本应用以全新三键只读界面替换 FoloToy AI Passport 的硬件演示入口，目标为 ESP32-C3、8 MB Flash、无 PSRAM。旧演示源码保留用于 BSP 回归测试，不编译进此应用。

## 界面与按键

0.2.3 在总览增加常驻的 Tibo 公告入口，与账户额度独立。上下键选择、确定进入保留的公告，长按确定返回原总览焦点；额度页原有公告切页仍保留。选中材质采用轻量边缘高光和八像素圆角，沿用原有 24 KiB LVGL 池，不分配实时模糊、渐变缓存或常驻动画。

总览显示运行中、待处理、今日完成的主任务数量，保留主机的全局统计，与有上限的近期任务列表区分。顶部显示最近快照来自 USB 或 BLE 以及送达年龄；“同步正常/超时”表示快照新鲜度，不据此推断物理连接。电池位于右上角，零电量保持有效。

上下键选择近期任务、近期提醒、账户额度或设置，确定进入。任务每行分开显示标题、客户端及状态、项目；左侧焦点标记和位置计数用于三行分页。长按确定返回并保留原焦点。快照重排时按确切 ID 保持当前任务、提醒或账户；详情中的任务离开八条投影时返回任务列表。

任务详情由基本信息、分类 Token 两页组成，上下键或确定均可切页。基本信息显示标题、项目、轮次、子任务数、墙钟耗时及独立来源年龄。六类 Token 分行显示，明确输入是否包含缓存、推理是否计入输出。额度上下切换账户窗口，确定切换用量/窗口/重置与来源/详细说明；仅绘制已提供的百分比，零保持有效。整天或整小时的窗口由来源分钟数直接格式化。

提醒确定标记已读，“已读待同步”保留至主机回执；设置也标记尚未同步的静音修改。新事件短暂显示标题和状态，确定确认，其他键只关闭弹层而保留未读。长文本在固定边界内以省略号结尾。

设置提供静音、25/70/100% 亮度、20 秒、60 秒及关闭自动息屏。电脑同步静音时段，默认本地 22:00-08:00；起止相同表示关闭静音时段。息屏后第一次按键只唤醒，不进入深睡或主动断开连接。新事件仅播放一次短双音；历史、重复事件、静音时段和手动静音不发声。

## 协议与资源边界

USB Serial/JTAG 与加密 BLE Nordic UART 共用换行分隔的 v1 JSON，单行上限 8192 字节。超长行丢弃至换行，不影响后续消息。投影最多八个任务、六个额度窗口、十二条提醒。UTF-8 按码点截断；缺失数字保持缺失，零保持有效，不估算额度。

主机 hello 得到设备 hello；每个有效快照回复带序号的 received。两条 hello 路径均从 IDF 应用描述符读取固件版本 0.2.3，与 CMake 项目版本一致。20 秒无快照标记离线，保留旧值及年龄，不改变任务终态。BLE 广播 AgentPassport-XXXX，支持两种写入分片，使用绑定的 Secure Connections 和六位显示码，在 Mac 输入此码配对。协议没有 Agent 审批、中断或执行命令。

已读确认和本地静音修改保存在设备 NVS 中，直到主机回复 acknowledged 或 mute_applied。重连快照不会撤销尚未同步的用户操作；重试具有幂等性，不重复播放事件声音。

快照已标记已读或设备有待同步确认时，晚到的旧事件不能恢复未读、亮屏或播放声音。快照中仍未读的新事件保持正常提醒。

任务用量详情和额度页分别显示来源观测时间；缺少来源时间时不使用快照时间替代。空项目名保持为空，零 Token 和零百分比保持可见。

JSON 和状态工作不在按键、LVGL 或无线回调执行；界面持 BSP 锁。音频独立任务复用 ES8311 和共享 I2C。沿用单个 20 行 DMA 缓冲和 24 KiB LVGL 池，不启动 Wi-Fi。

## 中文字体

assets/fonts/am_font_16.c 是 Flash 中的 Noto Sans CJK SC Regular 字体，16px、2bit、无压缩，旁边保留 SIL OFL。覆盖 ASCII、源字体的基本汉字 U+4E00-U+9FFF 及转换命令中的常用标点，不承诺任意 emoji 或补充平面汉字，保留缺字占位提示。位图超过小描述符 1 MiB 索引范围，因此启用大描述符。

使用 lv_font_conv 1.5.3 和官方 Noto 源字体转换：

```sh
lv_font_conv --font NotoSansCJKsc-Regular.otf \
  --range 0x20-0x7E,0x4E00-0x9FFF \
  --symbols '·，。！？：；（）【】《》、…→↑↓“”‘’—–～％￥' \
  --size 16 --bpp 2 --format lvgl --no-compress \
  --lv-font-name am_font_16 --lv-include lvgl.h \
  --output assets/fonts/am_font_16.c
```

## 验证

0.2.3 主机渲染新增公告直达、有内容公告和总览公告焦点，共 34 个画面及 200 次切页。0.2.3 单独构建和归档；真机验收仍是单独步骤，旧版本验收不能代替本镜像。

激活 ESP-IDF 5.5.3 后运行 ./tools/validate.sh，得到从 0x0 写入的 build/FoloToy-AI-Passport-full.bin 及匹配调试归档。完整镜像替换弃用应用并可能重置设置，无需整片擦除或读取旧固件。

协议测试覆盖 UTF-8 分片、溢出恢复、null 与零、静音边界、握手和快照确认、历史静默、重复事件、已读确认、三键导航，以及重排、移除、空快照时的 ID 焦点保持。cJSON 与 ESP-IDF 固定版本一致，其 macOS 第三方警告与应用严格检查分开。门禁在 macOS 选择本机链接器标志，并使用 Python SHA-256 校验 actionlint。

依赖下载后可用真实 UI 代码进行主机渲染：

```sh
cmake -S tests/ui -B /tmp/ai-passport-ui-build -G Ninja
cmake --build /tmp/ai-passport-ui-build
mkdir -p build/host-ui-0.2.3
/tmp/ai-passport-ui-build/am_ui_render tests/fixtures/am_ui_snapshot.json build/host-ui-0.2.3
```

31 张 240x320 PPM 使用实际界面、字库、BSP 圆角及合成测试值。渲染器按实际选用字体逐一检查当前文本字形、全部对象边界、文字容器互不重叠及已知缺失 emoji 的负例，并在原有 24 KiB LVGL 池内再切页 200 次。场景包含三个客户端、待同步回执、null/零 Token 和额度、空项目及列表、中文长标题、超时、来自 BLE 的快照及配对页。主机内存测量不证明设备可用堆或最大连续块。

0.2.3 仍需单独进行启动、屏幕及中文、按键、音频、电池、真实 USB 确认与重连、BLE 配对与分片、重连稳定性和运行内存验收。旧版真机结果不能替代新版验收。

## 重置公告

额度页确定键依次切换“剩余额度、来源与绝对重置时间、Tibo 公告”三页；
无额度窗口时仍能查看公告。剩余百分比只由来源已用百分比相减计算，
缺失数据保持未知。重置时间明确标记 UTC+8，不由公告猜测账户状态。

可选 resetNews 投影保留公告状态、短标题、时间原文、发布时间与检查时间。
原文不明确时不生成精确截止时间；公告只适用于 Codex，不适用于 BigModel。
新 reset_news 事件沿用未读、确认、静音和去重规则。原有任务计数不受影响。
主机渲染增加正常和过期公告两页，并检查三页导航、字形、边界及重复提醒。
本次构建不等同于烧录或真机验收；烧录和真机验收仍需单独完成。
